# ZIP 安全边界与旧同名条目

单来源最多 2048 个条目、单原件 32 MiB、展开总量 512 MiB、1 MiB 以上文件的压缩比不得超过 200。一次最多 128 个来源。XLSX 内部 ZIP 还受 64 MiB 展开限制，工作表最多 2048 个数据行、64 列。

支持普通单卷 ZIP。拒绝 ZIP64 容器、带前缀的自解压容器、加密和分卷 ZIP；在当前大小限制内不需要这些格式。名称须为 UTF-8 或 ASCII，请用系统压缩工具以 UTF-8 重新打包其它编码。未知文件忽略，路径和大小仍先检查。

旧 .NET 导出可能把两个同名原件放在 ZIP 根目录。zip 6 的内部名字映射会折叠重复名称；3.0 因此先验证结束目录、条目计数和中心目录边界，再为发票条目提供等长的虚拟目录名称。原文件不修改，解压和 CRC 校验仍交给 zip 库。每张原件按目录索引读取，保存原名称、索引和来源包 SHA-256，不按 ZIP 名字写入文件系统。

同名原件保留为不同草稿或按内容去重，Excel/JSON 映射无法唯一确定时交给人工。重复元数据名称或重复目录会拒绝，Manifest 必须精确一对一覆盖原件；同名容器的人工 Excel 配对还要匹配容器哈希。

所有原件保存到哈希地址，临时文件同步后独占提交。中途取消不提交半个压缩包的记录；导出已有同名目标时停止，原目标不覆盖。部分失败仅影响该来源，其他来源独立提交。
