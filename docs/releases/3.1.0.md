# LabInvoiceSystem 3.1.0

## 桌面体验

- 自定义应用标题栏：Windows 提供拖动、双击最大化/还原、最小化和安全关闭；macOS 保留原生交通灯。
- 隐藏横向与纵向滚动条，保留滚轮、触控板与键盘滚动。
- 使用 adapt 技能调整工作区、核对面板和字段布局；支持 640 × 480 的最小窗口，短窗口仍可访问完整操作。
- 导航、对话框、开关、拖放与按钮增加短时反馈动画，并遵循系统“减少动态效果”。

## 导入后自动 OCR

- 设置 → 百度 OCR 新增“导入后自动 OCR”，默认开启，旧配置缺少此字段时也采用开启状态。
- 首次导入或设置中明确授权后，逐张识别新导入且缺少完整元数据的原件；原有单张授权不会自动扩大为批量授权。
- 完整 Manifest、匹配 Excel 和历史 JSON 优先保留；部分结构化资料只补充缺失字段。识别后仍须人工核对和归档。
- 队列显示真实识别进度、成功/失败、保留数量与当前文件；支持取消、错误明细及仅重试剩余草稿。
- 网络等待可取消，已完成结果与剩余原件保持保存；成功结果与本地额度在同一事务记录。

## 发行状态

Windows NSIS 提供已验证的 Tauri Updater 数字签名。macOS Intel / Apple Silicon 提供 DMG 和带 Updater 签名的预览更新包；因 Apple 发行签名与公证凭据仍未提供，macOS 当前为 ad-hoc 未公证预览，继续排除在正式在线更新清单之外。

百度 OCR 服务可用性已由用户反馈确认；本次回归测试只使用合成验收资料，不上传用户真实发票。
