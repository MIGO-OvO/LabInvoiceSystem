# Desktop workbench

**Mode:** Operate.

**Authority:** 用户指定保留旧版 Slate/Indigo 和四项工作流。PRODUCT.md 的实验室成员与报账人员场景是设计上下文；新要求为自定义标题栏、隐藏滚动条、自适应、流畅动画与默认自动 OCR。

**Adapt:** 40px 标题栏、独立滚动主区和 34px 状态栏。窗口最小 640 × 480；主区 900px 以下单列核对，核对容器 420px 以下单列字段。宽屏继续侧栏，900px 以下沿用顶部导航。滚动条隐藏，内容和键盘焦点不隐藏。

**Motion thesis:** 短时变化连接状态，120ms 按压、180ms 页面/开关、220ms 模态进入、160ms 退出。transform / opacity 为主，减少动态效果关闭非必要动画。

**Flow:** 导入默认自动识别；批量上传授权明确且可撤回。结构化资料优先、失败草稿可恢复、完成不自动归档。窗口关闭继续使用发票操作排空路径。

**Verification:** Rust 队列与数据测试、真实 Tauri native 窗口调整、浅深主题 axe、设置持久化、减少动画和安全关闭。macOS 公证与真实设备完整人工验收仍须对应凭据与设备证据，不能由 Windows 模拟替代。
