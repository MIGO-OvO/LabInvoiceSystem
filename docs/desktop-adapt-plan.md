# 3.1.0 桌面体验与自动 OCR

## 范围与实施顺序

1. 为导入队列加入串行自动 OCR、真实进度、失败重试与取消；保留完整结构化元数据和历史上传授权边界。
2. 加入自定义标题栏，Windows 提供窗口按钮，macOS 保留系统交通灯。
3. 按 adapt 技能将窗口工作区、核对面板和字段按可用宽度重排；隐藏滚动条并保留所有滚动与键盘操作。
4. 按 animate 技能加入导航、对话框、开关和操作反馈；按 polish 技能检查最后细节。
5. 运行 Rust、前端、真实 Tauri 和安装验收；发布 3.1.0 并更新门户。

## 设计判断

延续 PRODUCT.md / DESIGN.md 的 Slate 与 Indigo、原有四个导航入口和核对工作流。窄窗口使用既有顶端导航；核对区以内容宽度为断点切为单列，金额、分类、原件和主操作始终可达。主工作区单独滚动，短窗口侧栏也可滚动，状态栏占有独立空间。

动效主线是状态连续性：页面切换用 180ms 淡入和 4px 位移，模态进入 220ms、退出 160ms，按钮按压 120ms、开关 180ms。使用 CSS transform / opacity，不增加动画依赖；减少动态效果设置关闭所有非必要动画。

自动识别默认开启。旧设置缺少字段时采用此默认值；既有单张 OCR 授权不自动扩大为批量授权。首次自动导入或设置中的明确授权允许上传新导入且缺少完整元数据的原件。识别不自动归档，失败和取消保留草稿；无需识别的 Manifest、Excel 和历史记录保持原字段。
