# LabInvoiceSystem 3.0.1

修复首次静默安装后 Windows 被动更新被安装语言选择对话框阻塞的问题。NSIS 使用系统匹配的安装语言；真实安装回归覆盖官方 `/P /UPDATE /R /ARGS` 参数、无人工输入完成安装和自动启动。

保留 3.0.0 的全部录入、分类、多 ZIP 只读预览、历史数据迁移、Manifest 无损回导和统计功能。数据格式、公钥和归档目录沿用 3.0.0。

## 安装、更新与验收

Windows x64 NSIS 与更新包经过 Tauri Updater 签名及签名版本验证；没有 Windows Authenticode 证书，首次安装可能出现 SmartScreen 提示。公开安装升级、归档原件和设置保留的实际结果见[验收记录](https://github.com/MIGO-OvO/LabInvoiceSystem/blob/main/docs/acceptance.md)。

**macOS Intel 与 Apple Silicon 当前仍为 ad-hoc 未公证预览构建。缺少 Apple Developer 发行证书和公证凭据，正式分发与 macOS 在线更新尚未完成；macOS 包排除于生产 `latest.json`。** 三架构的实际状态、校验和及更新签名见本 Release 的 `release-security.json`、`SHA256SUMS.txt` 与 `.sig`。
